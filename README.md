# Wagner Communication & Media Management

## Veröffentlichung über GitHub Pages

1. Neues öffentliches GitHub-Repository anlegen.
2. Alle Dateien aus diesem Ordner hochladen.
3. Unter Settings → Pages auswählen:
   - Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Unter Custom domain eintragen: wagnermediamng.com
5. DNS-Einträge beim Domainanbieter entsprechend den aktuellen GitHub-Pages-Hinweisen setzen.
6. HTTPS aktivieren.

## Vor Veröffentlichung prüfen

- Rechtsform ergänzen
- Umsatzsteuer-ID und Handelsregisterangaben ergänzen, falls vorhanden
- Impressum und Datenschutz rechtlich prüfen
- Optional Logo, Porträt und Social-Media-Links ergänzen
